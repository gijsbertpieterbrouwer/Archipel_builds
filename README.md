# Archipel

**Your IT landscape as islands in a sea.** Archipel is an enterprise architecture tool for
people who want to see and show how their organisation's applications, places and processes
hang together, without an expensive platform.

- **A landscape you understand at a glance.** Applications and places stand on islands like a
  model city: a maquette by day, a lit city by night. Connections run between them as pipes in
  the colour of what they carry.
- **Everything over time.** Move the time line and see what is being built, what is ending and
  how the landscape looks after a project.
- **Health at a glance.** What is wrong, what matters most and what to fix first.
- **More when you need it.** Processes, business objects, capabilities, costs, projects,
  strategy and architecture decisions are there when you want them.
- **Your data stays yours.** Everything is kept as plain files in a folder or a Git repository
  on your own computer. There is no Archipel server; your landscapes are never sent anywhere.

This repository holds the installers only. Download them from
[Releases](../../releases/latest).

## Install

### Windows

1. Download `Archipel-Setup-<version>.exe` from the latest release.
2. Run it. Windows may show "Windows protected your PC" the first time, because the installer
   is not signed with a paid certificate. Choose **More info**, then **Run anyway**.
3. Archipel starts. Later versions install themselves: you are asked once to restart.

### macOS

1. Download `Archipel-<version>.dmg` from the latest release.
2. Open it and drag Archipel to Applications.
3. The first time, right-click Archipel in Applications and choose **Open**, then **Open** again
   (macOS asks because the app is not notarised by Apple).
4. When a new version is out, Archipel tells you and opens the download page.

## First steps

1. Archipel asks where your workspace lives: start a new one, or open one your organisation
   already keeps on GitHub.
2. Make your first landscape: give it a name and add islands, groups and applications.
3. Click a block to see and change it; double-click to look inside. Ctrl+K searches everything.

Your workspace is a folder in Documents/Archipel. With GitHub, your team works in the same
workspace: Save keeps your changes, Sync shares them for review.
